# @amlplugins/google-youtube-analytics

Native `@googleapis/youtubeanalytics` SDK re-exported under the `@amlplugins` namespace.

> YouTube Analytics.

## Install

```bash
npm install @amlplugins/google-youtube-analytics
```

## Use

```ts
import { /* named exports from @googleapis/youtubeanalytics */ } from "@amlplugins/google-youtube-analytics";
// or
import sdk from "@amlplugins/google-youtube-analytics";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
